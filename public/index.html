Q1: Why ML instead of static rule-based countdowns?

Food spoilage is non-linear and governed by microbial kinetics ($Q_{10}$ temperature coefficient and Arrhenius reaction rates). At $35^\circ\text{C}$ room temperature, bacterial colony doubling time drops to 20 minutes, whereas at $4^\circ\text{C}$ refrigeration, growth is inhibited by $90\%$. Random Forest captures these multi-variable non-linear interactions accurately ($R^2 = 94.1\%$).

Q2: What is the Loss Function and Split Criterion?

The regression trees use Mean Squared Error (MSE) Variance Reduction at each node split: $\Delta\text{Var} = \text{Var}(Parent) - \sum \frac{N_k}{N}\text{Var}(Child_k)$. This minimizes residual sum of squares across predicted shelf-life hours.

Q3: How is real-time performance achieved?

Trained decision trees are serialized into JSON weights (ml/model_weights.json). Node.js executes the ensemble matrix directly in memory in under $2\text{ ms}$ without needing heavy external Python server processes.

Q4: How does this solve the real-world food waste problem?

By predicting the exact emergency threshold ($< 2.5\text{ hours}$), the system automatically triggers Red Alerts to volunteer drivers, ensuring nutritious hot surplus meals are rescued before bacterial spoilage occurs.
